# 🎧 Gemini Listen Speed Control

A lightweight Chrome extension that adds a dedicated playback speed control to Gemini's **Listen** feature.

The extension adds a small floating speed button that allows users to change the playback speed of Gemini's spoken responses without leaving the Gemini page.

## ✨ Features

- 🎚️ **Multiple playback speeds**
  - 0.75×
  - 1×
  - 1.25×
  - 1.5×
  - 1.75×
  - 2×

- 🔵 **Floating speed button**
  - Appears when Gemini's Listen audio is detected.
  - Displays the currently selected playback speed.

- 📋 **Dropdown speed menu**
  - Click the speed button to view available speeds.
  - The currently selected speed is highlighted.
  - The menu closes automatically after selecting a speed.

- 🌙 **Light & Dark theme**
  - Automatically adapts to the system's light/dark theme.
  - Uses a clean, Gemini-inspired interface.

- ⚡ **Instant playback changes**
  - The selected speed is immediately applied to Gemini's audio.

# 🎧 Gemini Listen Speed Control

A Chrome extension that adds a simple **playback speed control** to Gemini's **Listen** feature.

Users can choose between **0.75×, 1×, 1.25×, 1.5×, 1.75×, and 2×** while Gemini is reading a response aloud.

## ✨ Features

- 🎚️ Playback speeds: 0.75× to 2×
- 🔵 Floating speed button
- 📋 Dropdown speed menu
- ✓ Highlights the selected speed
- 🌙 Light/dark themed interface
- ⚡ Changes playback speed instantly
- 🖥️ Works directly on Gemini's website
- 🔒 No external server or database required
